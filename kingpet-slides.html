KIẾN TRÚC CLIENT-SERVER & CSDL NEON CLOUD POSTGRESQL 18.7

Hệ thống cơ sở dữ liệu đám mây Serverless trên AWS US-East-2 (Ohio), hỗ trợ SSL Require & Connection Pooling 24/7.

1. Khung nhìn kiến trúc 3 tầng (C&C View)
Architecture Design
  • Tầng Trình Diễn (Client Presentation):
    • Storefront (index.html): Giao diện người dùng mua sắm Hoàng Gia, Drawer Cart, VietQR.
    • Admin Portal (admin.html): Cổng quản trị điều hành SPM, Dashboard KPI, Tab Neon Cloud CSDL.
  • Tầng Backend (Python Server API):
    • server.py: RESTful API (/api/db/status, /api/auth/login, /api/auth/forgot-password, /api/orders, /api/products).
    • Cơ chế bảo mật 2 lớp: Sinh mã OTP ngẫu nhiên 6 số và lưu trữ trạng thái phiên xác thực.
  • Tầng Dữ Liệu (Neon Serverless PostgreSQL):
    • Cơ sở dữ liệu đám mây Neon PostgreSQL 18.7 (AWS US-East-2 Ohio), kết nối pooler an toàn qua SSL.
    • Dual-Layer Architecture: LocalStorage Client Caching + Cloud Database đạt độ sẵn sàng 99.9%.
